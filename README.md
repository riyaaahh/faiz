# Mohammed Faiz — Portfolio

Premium portfolio website for **Mohammed Faiz**, Digital Marketing Executive.

## Tech Stack

- React (Vite)
- Tailwind CSS v4
- Framer Motion
- Lucide React icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Sections

- Hero with animated intro & stats
- About Me with certifications & languages
- Hard & Soft Skills with animated progress bars
- Work Experience (Zoople Technologies)
- Contact form & reference details
